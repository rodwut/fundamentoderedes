
Una red computacional es un sistema complejo de intercambio de informacion, requiriendo una combinacion de infraestructura fisica y reglas logicas para una comunicacion efectiva

### Nodos (Origen y Destino)
Son dispositivos que envian y reciben datos dentro del ecosistema de la red

### Enlaces (Camino Fisico)
Modelos fisicos o inalambricos que establecen la conexion entre los diferentes nodos

### Direcciones (Identidad Digital)
Identificadores IP y MAC unicos que permiten localizar dispositivos de origen y destino

### Protocolos (Lenguaje Común)
Reglas estrictas de formato y sintaxis que rigen la comunicacion entre dispositivos

### Enrutamiento (Gestion de Rutas)
Proceso de decision para determinar el camino mas eficiente para los datos
